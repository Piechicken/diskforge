# DiskForge 完整收敛验收清单

> 本清单定义后续统一交付的验收边界。任何条目不得仅以菜单、占位对话框或不可测试的声明计为完成；每一项均需要可执行服务、可发现的桌面工作流，以及覆盖成功、取消或拒绝路径的严格自动化测试。

## 已完成且需要持续回归

| 能力域 | 已交付基线 | 持续验收条件 |
|---|---|---|
| 映像工作区 | FAT、ISO、RAW、固定 VHD、DMF、兼容转换、可选只读 NTFS/EXT | 打开、检查、浏览、提取、失败诊断均在四平台测试中通过。 |
| 安全结构操作 | 启动扇区备份编辑、MBR 生命周期、GPT 诊断、比较、缩放、零尾裁剪 | 所有字节修改写入新文件或预先备份，坏输入被拒绝。 |
| 内容管理 | FAT 注入、删除、重命名、属性、时间、卷标、提取策略 | 递归目录、冲突策略、取消和元数据保真均有回归测试。 |
| 分发与自动化 | 安全容器、自解压包、CLI、JSON 批处理、顺序命名 | 清单、路径安全、哈希校验与脚本化退出码可验证。 |
| 桌面体验 | 七语言与 RTL、拖放、预览、最近文件、详细/图标视图、主题、批处理设计器 | 离屏启动、语言切换、拖放协议、视图状态和主题切换可验证。 |
| 物理设备安全 | 设备发现、读取、受确认保护的写入、比较、光学介质 ISO 读取 | 系统盘、已挂载目标、容量不足及只读光学介质被安全处理。 |

## 已在 v0.6.0 收敛并纳入严格回归

| 编号 | 可观察能力 | 已交付验收结果 |
|---|---|---|
| C-01 | FAT/ISO/虚拟磁盘的完整打开策略 | 固定 VHD 通过隔离临时 RAW 数据会话只读浏览并排除 VHD 尾部；已配置转换器的格式采用同样的只读临时会话；关闭与失败均清理临时数据。 |
| C-02 | 可引导 ISO 创作 | 从目录与可选本地启动映像创建 ISO；支持 El Torito 媒体模式与 boot-info-table；创建结果可由只读目录检查，且源启动映像不变。 |
| C-03 | 启动扇区结构化与模板工作流 | 现有 FAT 字段编辑继续受边界校验；原创中性/消息模板保留 BPB、写入前备份，并具有成功与拒绝路径测试。 |
| C-04 | FAT 映像部署计划 | FAT 映像可生成独立的中性 MBR 单分区部署文件，显示可审阅分区计划；实际设备写入仍只通过容量、挂载、系统盘和 `ERASE` 保护的独立路径。 |
| C-05 | 传统介质报告策略 | 比较可选仅报告忽略完整扇区对齐的末尾零区；默认仍严格比较，输入绝不改写。 |
| C-07 | 可移植偏好 | 支持显式 `--portable`、显式目录与环境变量，使用独立 INI 保存语言、最近文件、视图、主题、字体及外部工具配置。 |
| C-08 | 任务与通知中心 | 任务中心显示排队、运行、完成、失败与取消状态，可清理已完成记录，并保留取消和错误提示。 |
| C-10 | 公开 API 与命令行一致性 | `diskforge.api` 提供类型化安全入口；新核心流程具备 CLI、JSON 输出、预演或明确的拒绝语义。 |

## 仍需持续扩展的验收范围

| 编号 | 可观察能力 | 必须交付的验收结果 |
|---|---|---|
| C-06 | 图形自动化全流程 | 将图形设计器从目前的安全顺序提取扩展为转换、验证、比较、缩放、注入、容器的可视化配方编辑、重新打开与逐项结果审阅；无人值守原始设备写入始终拒绝。 |

## 发布总门槛

发布候选必须同时满足：默认 pytest 严格配置下零警告通过；核心、GUI、CLI、损坏输入和取消路径均有自动化覆盖；Linux 离屏主窗口与七语言验证无诊断输出；四个平台的构建、打包、校验清单及公开发行全部成功。任何依赖操作系统、权限、外接硬件或外部适配器的能力均要在 UI、CLI 和文档中准确披露，不可将不可用能力显示为已完成。
