# 界面语言与本地化

DiskForge v0.8.0 提供可在运行时切换的桌面界面语言。语言偏好保存在本机 Qt 设置中，下一次启动时会自动恢复。切换入口位于 **Tools → Language**；切换会立即更新现有窗口、菜单、工具栏、标签页、表格列标题和后续显示的常用对话框，不需要重新启动。

## 支持范围

| 代码 | 语言 | 状态 | 文字方向 |
|---|---|---|---|
| `ar` | العربية | 联合国工作语言 | 从右到左（RTL） |
| `zh_CN` | 简体中文 | 联合国工作语言 | 从左到右（LTR） |
| `en` | English | 联合国工作语言 / 默认语言 | 从左到右（LTR） |
| `fr` | Français | 联合国工作语言 | 从左到右（LTR） |
| `ru` | Русский | 联合国工作语言 | 从左到右（LTR） |
| `es` | Español | 联合国工作语言 | 从左到右（LTR） |
| `ja` | 日本語 | 附加语言 | 从左到右（LTR） |

阿拉伯语切换会将 Qt 应用的整体布局方向切换为 RTL，使菜单、分栏、文本对齐和操作顺序在从右到左环境中保持自然。文件名、扇区十六进制数据、哈希值、设备标识符和磁盘路径属于技术数据，程序会按原值显示，不会进行语义转换。

## 翻译资源设计

翻译目录位于 [`diskforge/gui/i18n.py`](../diskforge/gui/i18n.py)。每个条目采用英文源文本作为稳定键值，运行时语言管理器会记录控件的原始文本并安全更新已创建的控件；动态进度、文件路径和错误诊断不会被覆盖。新界面文本应使用现有英文源文本，随后在 `CATALOG` 中加入全部支持语言的对应翻译。v0.4.0 已为 DMF 创建、FAT 映像 MBR 封装、尾部零扇区裁剪及 ISO El Torito 引导映像检查/导出添加七语言标签与说明。v0.5.0 已将文件预览、最近映像、详细/图标视图、批处理提取设计器、浅色/深色外观和光学介质 ISO 读取入口纳入七语言目录。v0.6.0 已将 FAT 部署计划、可启动 ISO 的启动映像与介质模式、原创启动模板、任务中心和界面字体偏好纳入七语言目录。v0.7.0 进一步将工作区品牌、内置历史文件预览、传统压缩包标签、可执行文件安全检查与二进制检查纳入七语言目录。v0.7.5 则补齐文档工作区的编辑、查找、另存副本、保存回 FAT 映像、Office/OpenDocument 预览状态、批处理全操作配方与逐项结果、文件系统适配器错误提示及动态关于对话框。v0.8.0 新增 FAT 模板布局、启动代码安全导入、固定 VHD 可编辑副本、外部转换器能力状态、受控 DMG 转换与只读物理介质采集队列的全部七语言标签、说明、错误和审计报告词条；回归测试会防止这些关键标签在任何非英语界面回退为英文源文本。

> 本地化不得改变危险操作的确认短语、路径、文件扩展名、校验和或底层映像格式标识。尤其是物理写入仍必须准确输入 `ERASE`，无论当前界面语言为何。

## 验证

自动化测试检查联合国六种工作语言和日语是否已注册、语言偏好是否持久化、阿拉伯语是否启用 RTL，以及用户连续切换语言是否能更新已创建的控件。测试还要求文档编辑、保存回写、文件系统错误提示和批处理工作流在所有非英语语言中具有实际翻译。pytest 启用严格配置、严格标记及警告即错误质量门槛。离屏 GUI 冒烟脚本会遍历全部语言并生成阿拉伯语界面截图。

```bash
QT_QPA_PLATFORM=offscreen pytest
QT_QPA_PLATFORM=offscreen python scripts/gui_i18n_smoke.py
```

四平台持续集成会运行同一套自动化测试；Linux 构建还会执行离屏 GUI 验证。
