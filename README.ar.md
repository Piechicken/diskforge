> **يمنح DiskForge صور الأقراص مساحة عمل حقيقية على سطح المكتب.** أنشئ وتحقق وتصفح واستخرج وادخِل وحوِّل وتحقق واستعد الصور بأمان دون التعامل مع القرص الفيزيائي كخيار ثانوي.

## تنزيلات الإصدار

يوفر الإصدار الرسمي v0.10.0 أربعة بنى أصلية لسطح المكتب. قم بتنزيل الحزمة المطابقة لنظام التشغيل الخاص بك من صفحة [Releases](https://github.com/Piechicken/diskforge/releases): **Windows x64**، **Linux x64**، **macOS Intel**، أو **macOS Apple Silicon**. كل حزمة تُبنى وتُتحقق في GitHub Actions على جهاز التشغيل الهدف.

| النظام | الحزمة | التشغيل |
|---|---|---|
| Windows x64 | `DiskForge-v0.10.0-windows-x64.zip` | فك الضغط، ثم شغّل `DiskForge.exe`. |
| Linux x64 | `DiskForge-v0.10.0-linux-x64.zip` | فك الضغط، ثم شغّل `./DiskForge`. |
| macOS Intel | `DiskForge-v0.10.0-macos-intel-x64.zip` | فك الضغط، ثم انقل `DiskForge.app` إلى Applications. |
| macOS Apple Silicon | `DiskForge-v0.10.0-macos-arm64.zip` | فك الضغط، ثم انقل `DiskForge.app` إلى Applications. |

## لغات الواجهة

يقوم DiskForge v0.10.0 بتوطين مساحة الوثائق وقالب FAT، واستيراد شيفرة التمهيد الآمن، وVHD ثابت قابل للتحرير، واختيار القسم، واستبدال ISO الآمن، وحاوية ZIP القديمة، والتركيب للقراءة فقط، وMBR للجهاز، والوسائط القابلة للإزالة، ووحدة تحكم المرن، ومسارات الفلوبي USB UFI المحمية أثناء وقت التشغيل. اختر **Tools → Language** للتبديل الفوري بين ست لغات عمل للأمم المتحدة—**العربية، الصينية، الإنجليزية، الفرنسية، الروسية، والإسبانية**—بالإضافة إلى **اليابانية**. يتم الاحتفاظ بالتفضيل لوقت التشغيل التالي. عند اختيار العربية ينتقل تخطيط Qt بالكامل إلى الاتجاه من اليمين إلى اليسار مع الحفاظ على القيم التقنية مثل مسارات الأجهزة، والمجاميع الاختبارية، وامتدادات الملفات، وعبارة تأكيد الكتابة الفيزيائية `ERASE`. تغطية واجهة UFI لا تعني قبول تنسيق الأجهزة الحقيقية مكتملًا.

اقرأ [LOCALIZATION.md](docs/LOCALIZATION.md) لمصفوفة اللغات، وسلوك RTL، وحدود الأمان، وسير عمل صيانة الترجمة.

## ما الذي يفعله

يجمع DiskForge أهم سير عمل إدارة الصور في تطبيق أصلي واحد يمكن تدقيقه. تجمع النافذة الرئيسية بين مستكشف الصور، وجدول الدليل، ولوحة بيانات التعريف للصورة، وسجل النشاطات، ومنطقة التقدم القابلة للإلغاء. تُعزل الإجراءات المدمرة بصريًا عن التصفح العادي وتطلب تأكيدًا صريحًا.

| سير العمل | القدرة الأصلية | ملاحظات |
|---|---|---|
| إنشاء صور | RAW/IMG/IMA, FAT12, FAT16, FAT32, ملفات فلاپي FAT12 القديمة الموثوقة، DMF-layout FAT12، قوالب FAT، ISO9660/Joliet/Rock Ridge/UDF، HFS الكلاسيكية الاختيارية | أنشئ صور FAT قابلة للتحرير من إعدادات مسبقة قياسية، أو من قالب BPB FAT مُثبت، أو من ملفات تعريف IMG/IMA القديمة الصريحة للفلوبي. يغطي الملف القديم التخطيطات التقليدية المتوافقة مع الحاسب الشخصي من 160 KiB حتى 2.88 MiB وهندسة CHS المخصصة المدعومة. يمكن إنشاء وسائط ISO من دليل محلي مع وسائط تمهيد El Torito اختيارية. مع توفر `hformat` صراحة، يمكن لـ DiskForge إنشاء صورة ملف عادية HFS كلاسيكية جديدة مستقلة من 800 KiB فما فوق؛ تبقى HFS+ للقراءة فقط. |
| التصفح والاستخراج | FAT12/16/32—بما في ذلك وسائط الفلوبي DOS القديمة غير المعنونة الموثوقة وأسماء RAW المستعارة `.vfd`/`.flp`/ذات لاحقة السعة بالحجم التقليدي—مرشحين محافظين لملفات الجذر المحذوفة في FAT12/FAT16؛ IMD وTD0 وCPC DSK وD88 وAPRIDISK وCopyQM وSAP وMSA وPSI وDC42 و2MG/2IMG وHFE وPRI و86F المقيدة وFDI وJV3 وDMK وUDI v1.0 وSCP القياسية وفحص حاوية HxC MFM القياسية وحاوية تدفق PCE PFI v0 القياسية وحاوية Apple II WOZ 2.0/2.1 القياسية وحاوية تدفق A2R 3.x القياسية وحاوية G64 v0 1541 GCR القياسية وحاوية G71 v0 1571 GCR القياسية ثنائية الوجه وحاوية نبضات P64 v0 1541 NRZI القياسية للمعاينة؛ ISO9660/Joliet وحاويات ZIP الآمنة متعددة الصور ذات الاختيار الصريح، ومعاينات VHD الثابتة، وخلفية قراءة فقط اختيارية لـ NTFS/EXT2/EXT3/HFS الكلاسيكي/HFS+ | يتم تجسيد ملف ZIP عادي يحتوي من حمولة صورة آمنة واحدة إلى 64 حمولة على مستوى الجذر فقط في جلسة خاصة للقراءة فقط يتم تنظيفها تلقائيًا. تُفتح الحمولة الوحيدة مباشرة؛ أما ZIP متعدد الصور فيتطلب اختيار حمولة واحدة صراحة في سطح المكتب أو CLI أو SDK. لا يصبح قابلاً للكتابة أو للتحويل. لا تُصنَّف أسماء RAW المستعارة القديمة إلا عندما يتطابق لاحقتها وحجمها الدقيق بالبايت مع شكل قرص مرن تقليدي للحاسب بقطاعات 512 بايت؛ ولا تُخمن وسائط القطاعات المتغيرة أو XDF أو GCR أو القطاعات الصلبة أو التدفق. تتجنب الأشجار المصفحة والجداول القابلة للفرز عرض دلائل غير محدودة. يتم دائمًا اختيار أقسام MBR/GPT الموثوقة بواسطة فهرس الجدول الصريح: يحتفظ FAT بمسار التحرير الحالي، بينما يتم فتح NTFS/EXT/HFS الكلاسيكي/HFS+ فقط عند إزاحة مؤكدة وصحيحة عبر الخلفية للقراءة فقط. النقر المزدوج يفتح مساحة عمل وثيقة غير قابلة للتنفيذ للنصوص والصور والأرشيفات الشائعة وحزم الإعداد القديمة والبرامج التنفيذية والبيانات الثنائية. يمكن العثور على المستندات النصية وحفظها كنسخة—وفقط لمدخلات FAT القابلة للكتابة—وتحريرها وحفظها مرة أخرى. عادةً ما يفتح VHD الثابت عبر معاينة بيانات RAW للقراءة فقط مؤقتة؛ يمكن إعادة فتح نسخة VHD ثابتة مستقلة موثوقة كجلسة FAT قابلة للكتابة. |
| جرد أدلة الصور | مسح بيانات تعريف الصور المحلية للقراءة فقط مع تقارير JSON أو CSV أو HTML | امسح دليلًا محليًا واحدًا، اختياريًا بشكل تكراري، وصفي المرشحين المعروفين حسب اللاحقة، أو الصيغة المعترف بها، أو نظام الملفات، أو مجال البايت، أو بادئة SHA-256. يمكن تضمين SHA-256 لكل سجل وملخصات الأقسام اختياريًا. كل تقرير هو ملف جديد خارج الجذر المفحوص؛ لا يتم تعديل أي صورة مرشحة. |
| تغيير محتويات الصورة | حقن FAT، إنشاء مجلد فارغ صريح، مجلدات متكررة، حذف، إعادة تسمية، نسخ ملفات وأشجار دلائل عبر الدلائل مع نقل مسيطر عليه، الطوابع الزمنية، سمات DOS، ووسوم الحجم؛ تحريرات ISO آمنة قائمة على إعادة البناء؛ حقن NTFS/EXT/HFS الكلاسيكي الاختياري عبر أدوات خارجية | تتشارك حمولات FAT الصالحة داخل IMG وIMA نفس المسار القابل للتحرير. يمكن إنشاء دليل فارغ صراحة فقط على مسار جديد يكون أبوه موجودًا بالفعل؛ هذا لا يكتب فوق أو ينشئ آباء ضمنيين. يمكن نسخ ملف عادي أو شجرة دليل كاملة إلى دليل موجود دون استبدال؛ النسخ يحافظ على المصدر، يتطلب هدفًا جديدًا بنفس الاسم، ويرفض هدف دليل داخل شجرة المصدر. يمكن أيضًا نقل ملف أو شجرة دليل إلى مثل هذا الهدف: يكمل الدليل أولاً عملية نسخ قابلة للإلغاء، ثم يزيل مصدره. الإلغاء قبل الحذف أو فشل الحذف يحتفظ بكلتا الشجرتين المكتملتين للحل اليدوي، لذلك لا يُدعى أن حركة الدليل ذرية. تُرفض الأهداف المفقودة/غير-الدليلية، ونقل الجذر، والتصادمات، والجلسات للقراءة فقط، وهداف شجرة المصدر قبل أي تغيّر. تظل إعادة التسمية في نفس الدليل إجراءً منفصلاً. يحذف حذف FAT الصريح ملفًا واحدًا غير جذري أو شجرة أدلة بعد التحقق من المسار؛ وهو غير قابل للعكس ولا يُدعى أنه معاملة ذرية. تغييرات ISO دائمًا تكتب صورة معاد بناؤها منفصلة وتتحقق من المحتوى المرحَّل. تُحفظ ملفات Rock Ridge/UDF؛ يُعاد بناء إدخال El Torito المؤكد الوحيد فقط، بينما تُرفض التمهيدات المتعددة، والهجينة، والتخطيطات المبهِمة. مع توفر `ntfsprogs` أو `e2fsprogs` أو `hfsutils` صراحة، يمكن لـ NTFS/EXT/HFS الكلاسيكي استقبال ملفات جديدة في جذر الدليل فقط في صورة إخراج منفصلة تم التحقق منها؛ لا يُسمح بكتابة المصدر أو إزاحة القسم أو بيانات التعريف أو إعادة التسمية أو الحذف أو الاستبدال. ينقل حقن HFS الكلاسيكي شوكات البيانات الأولية فقط؛ تبقى HFS+ للقراءة فقط. |
| تحويل الصيغ | RAW/IMG/IMA وVHD ثابت محليًا | تحافظ IMG وIMA على امتداد الصورة الخام المحدد صراحةً أثناء التحويل. تستخدم VHDX وVMDK وQCOW2 محول `qemu-img` مكوّن صراحة مع تقرير قدرة مرئي وإمكانية الإلغاء. يمكن لمحوّل `dmg2img` المُكوَّن بشكل منفصل إنشاء إخراج RAW جديد فقط من DMG؛ لا يقوم DiskForge بتركيب أو كتابة ملفات DMG. |
| ضغط صور FAT | إلغاء التجزئة قائم على إعادة البناء | يكتب صورة جديدة، مع الاحتفاظ بالصورة الأصلية كنقطة استرداد. |
| تفحص وإصلاح البنى | عارض/محرر سداسي بواجهة 512 بايت، خصائص تمهيد FAT المُثبتة، قوالب محايدة/رسائل أصلية، تغليف MBR محايد وتخطيط النشر لصور FAT superfloppy، تقليم نسخة القطاعات النهائية الصفرية، نسخ/استعادة/إعادة تعيين MBR، وتشخيصات GPT CRC | تُنشأ نسخ احتياطية كاملة للصورة أو MBR قبل التغييرات الهيكلية المحمية. تحافظ القوالب على حقول BPB ولا تستخدم برنامج تمهيد مستورد؛ التغليف، والتحضير للنشر، والتقليم دائمًا يكتبون ملفًا جديدًا. |
| تحقق وأتمتة | SHA-256، مقارنة بايت-بِبايت، استوديو وصفات دفعات رسومي، خطط قبل الطيران، مراجعة نتائج لكل عنصر، وصفات JSON ذات إصدارات، وتقارير الدليل | يضيف المخطط v4 إعلانات `iso_edit`، `ntfs_inject`، `ext_inject`، `hfs_inject`، `hfs_create`، `export_listing`، FAT `move`، `fat_mkdir`، `fat_copy`، `fat_rename`، `fat_delete`، و`fat_metadata` بمسار صريح؛ يمكن معاينة كل كتابات الوصفات قبل التنفيذ وتبقى كتابات الأجهزة الخام مرفوضة. يقوم `export_listing` فقط بإنشاء تقرير نصي/HTML محلي ويمكن أن يستهدف قسمًا للقراءة فقط محددًا صراحة. تستخدم تقارير الدليل النصية/HTML جولة كاملة ثابتة لكل نظام ملفات قابل للتصفح وقسم للقراءة فقط محدد صراحة. يغطي المصمم الرسومي التحويل—بما في ذلك اختيار هدف IMA—والتحقق والمقارنة والتغيير في الحجم والحقن وإنشاء HFS الكلاسيكي والاستخراج ووصفات الحاويات. يمكن للمقارنات أن تبلغ اختياريًا عن قطاعات صفرية كاملة في النهاية كمهملة فقط. |
| التعليقات وتغيير الحجم | تعليقات على الصور غير تدخلية وتغيير حجم RAW/FAT لملفات جديدة آمن | ترفض الصور الخام التقليص إذا كانت البايتات الطرفية غير الصفرية ستُفقد. |

FDI v2.0 وDMK وHxC MFM القياسية وPCE PFI v0 القياسية وWOZ 2.0/2.1 القياسية وA2R 3.x القياسية وG64 v0 القياسية وG71 v0 القياسية وP64 v0 القياسية هي فاحصات حاويات بنيوية للقراءة فقط: لا يفك أي منها المسارات أو تدفقات البتات أو التدفق، ولا يفتح نظام ملفات، ولا يحول، ولا يصلح، ولا يكتب، ولا يعيد بناء بيانات RAW. كما أن JV3 للقراءة فقط؛ ينتج إخراج RAW منفصلًا فقط بعد أن تثبت القطاعات العادية تخطيطًا مستطيلًا واحدًا مكتملًا وثابت الهندسة. كل متغير حاوية تاريخي آخر يحتفظ به للاستعراض فقط أو يُرفض بدلًا من أن يُخمن أو يتسطح.

## السلامة أولًا

> يجب أن تجعل أداة صور الأقراص العمليات الخطرة "صعبة التحفيز عن طريق الخطأ".

لا يركّب DiskForge صورة أبدًا أو يكتب على جهاز فعلي تلقائيًا. ينتج نشر FAT أولًا صورة MBR محايدة يمكن مراجعتها؛ ولا يتجاوز عملية الكتابة الفيزيائية المحمية. قبل الكتابة الفيزيائية، يتحقق من السعة، والحالة المركبة، وحالة قرص النظام، ثم يتطلب العبارة الدقيقة `ERASE`. يمكن لمسار الكتابة أن يتحقق من البايتات بعد الاكتمال. كما تُنشأ نسخة احتياطية كاملة للصورة قبل تغييرات قطاع التمهيد. اعمل دائمًا مع صور اختبار قابلة للتخلص قبل العمل على وسائط لا يمكن استبدالها.

## إعداد محمول

استخدم `diskforge --portable` لكتابة التفضيلات، وخيار اللغة، والصور الأخيرة، ووضع العرض، والثيم، والخط، ومسار الأداة الخارجية إلى `DiskForgeData/diskforge.ini` في الدليل الحالي. استخدم `--portable=DIR`، `--portable-directory DIR`، أو `DISKFORGE_PORTABLE_DIR` لاختيار موقع صريح. يستخدم هذا الوضع ملف INI محمول عادي ولا يتطلب إدخال سجل نظام.

| حاوية صور ZIP (`.zip`) | بنية ZIP ومن حمولة مرشحة موثقة واحدة إلى 64 حمولة | قراءة/قائمة/استخراج/تقرير فقط بعد تجسيد مؤقت مُنظف تلقائيًا؛ يتطلب الأرشيف متعدد الصور اسمًا مختارًا صراحة | لا إنشاء، أو تحويل، أو تحرير نظام ملفات، أو كتابة أرشيف. يجب التحقق من كل حمولة جذرية غير مشفرة Stored/Deflated بامتداد `.img`، `.ima`، `.bin`، `.dd`، `.dmf`، `.vfd`، `.flp`، أسماء السعة المستعارة، `.d64`، `.d71`، `.d81`، `.iso` أو `.hfs` حتى 2 GiB؛ ويرفض أي عضو غير آمن الحاوية. |
| حزمة DiskForge (`.dfb`) | رأس وmanifest موثَّق | استخراج والتحقق؛ حماية كلمة مرور AES-256-GCM اختيارية | الإنشاء من صورة محلية واحدة أو أكثر. |
| كتالوج التمهيد El Torito | فحص | تصدير صورة التمهيد؛ الحفاظ الآمن على مدخل أول مؤكد أثناء إعادة بناء ISO | إنشاء وسائط ISO قابلة للتمهيد من دليل وصورة تمهيد محلية اختيارية. تُرفض الخرائط متعددة الأقسام/متعددة التمهيد، أو منطقة النظام المختلطة، أو الخرائط المبهمة أثناء إعادة البناء. |
| DMG | تلميح توقيع | لا يتم تعديله محليًا | استخدم سير عمل خارجي متوافق. |

يكشف DiskForge مسارات التحرير غير المدعومة بصدق بدلًا من محاولة كتابات غير آمنة. مفتشات الحاويات التاريخية هي عقود قراءة فقط محددة بالصيغ عمدًا: لا يقوم HFE وPRI و86F المقيد بفك تشفير تدفقات البتات أو إنتاج RAW؛ يُصدّر DC42 و2MG/2IMG مناطق بيانات مستقلة مؤكدة فقط؛ يصدر APRIDISK وCopyQM وSAP وMSA وPSI ملف RAW جديدًا فقط بعد أن يثبت محللوها فرديًا بيانات عادية مكتملة ومستطيلة. يتحقق G71 v0 القياسي فقط من توقيع `GCR-1571` الثابت للإصدار 0، و168 إدخالًا بالضبط لنصف المسار، وجداول المسارات والسرعة little-endian المحدودة، وتخصيصات المسارات المخزنة غير الشفافة، ومناطق السرعة الثابتة أو المعينة، وعدم التداخل، ونهاية الملف المطابقة؛ وتبقى بايتات GCR معتمة دون فك GCR أو القطاعات أو تصدير RAW أو التصفح أو جلسة نظام ملفات أو التحويل أو الإصلاح أو الكتابة. ترفض كل حاوية من هذه الكتابات المصدرية أو التحويل العام أو جلسات نظام الملفات أو المخرجات الموجودة أو الأجهزة أو الإصلاح أو المتغيرات غير المدعومة. الجرد الدفعية هو سير عمل تقرير محلي للقراءة فقط، وليس ماسحًا جنائيًا أو تغييرًا بلا إشراف: يقبل دليلًا واحدًا موجودًا غير رابط رمزي، يتجاهل الروابط، يتعرف على لاحقات الصور المعروفة فقط، يجد بحد أقصى 10,000 ملف عادي، يستبعد الملفات فوق 16 GiB، ويكتب تقرير JSON/CSV/HTML جديدًا خارج جذر الفحص فقط. لا يقوم بتركيب الصور، أو فحص الأجهزة الفيزيائية، أو الكتابة فوق التقارير، أو دخول مخطط دفعي v4. يتم فحص IMD كحاوية قطاعات فلوبي ولا يُعامل تلقائيًا كـ RAW أو نظام ملفات قابل للكتابة. يمكن تصدير ملف RAW جديد فقط من تخطيط CHS مستطيل مكتمل مع عدد/حجم قطاع ثابت، ومعرّفات متتالية `1..N`، وبدون خرائط اختيارية، وبيانات قطاعات عادية (بما في ذلك تعبئة مضغوطة عادية). TD0 هو كذلك حاوية قطاعات، وليس نظام ملفات RAW أو قابل للكتابة: يتم فحص سجلات `TD` العادية غير المضغوطة فقط، مع تحقق من CRC للرؤوس/التعليقات/المسارات/القطاعات. يتطلب تصدير RAW الجديد أيضًا EOF دقيق، وقطاعات غير موسومة، وتطابق CHS الفيزيائي والمنطقي، وهندسة ثابتة، وإعادة بناء دقيقة للبيانات العادية/النمط المتكرر/RLE. يتم رفض السجلات `td` المضغوطة المتقدمة، والسجلات متعددة الأجزاء، وفشل CRC، والعلامات أو البيانات المفقودة، والكثافة المختلطة، والهندسة غير المنتظمة، واستبدال الإخراج، وكتابة TD0، والتحرير، والإصلاح، والأجهزة، وادعاءات تدفق/فتحة البتات. تُرفض الهندسة غير المنتظمة، والقطاعات المفقودة/المحذوفة/التالفة، والتخطيطات المتغيرة، والسجلات المكررة، والخرائط، والبايتات الطرفية، والأهداف الجهازية، والاستبدالات، وكتابة IMD، وأي ادعاء تدفق/فتحة بتات. استرداد ملف FAT المحذوف هو سير عمل ضيق "نسخ المرشح" وليس استردادًا جنائيًا عامًا: يقبل فقط فتحات 8.3 عادية لجذر FAT12/FAT16 ثابتة مع حمولة موجبة لا تزيد عن عنقود واحد وبداية عنقود حاليًا حُرَّة. الحرف الأول من اسم الملف المحذوف غير متاح؛ قد تكون البايتات المرشحة قديمة أو مستبدلة، لذا لا يُدعى اسم أصلي أو سلامة. يتم رفض FAT32، والفرعيّات، والأسماء الطويلة، وسلاسل متعددة العناقيد أو صفر الطول، والعناقيد المشغولة، وكتابات المصدر، واستبدال الإخراج الموجود، واسترداد الجهاز، والاسترداد الدفعي. الأرشيف ZIP العادي هو حاوية صور ضيقة للقراءة فقط، وليس نظام ملفات عام أو مصدر تحويل: يمكنه احتواء من حمولة جذرية آمنة واحدة إلى 64 حمولة غير مشفرة Stored/Deflated بامتدادات صور معتمدة، ولا تتجاوز كل حمولة 2 GiB. تُفتح الحمولة الوحيدة مباشرة؛ أما الحمولات المتعددة فتتطلب اسمًا جذريًا دقيقًا مختارًا صراحة في سطح المكتب أو CLI أو SDK. تُرفض المجلدات، والأسماء غير الآمنة، والتشفير، والضغط غير المدعوم، والحمولات الفارغة/المتضخمة/غير المعروفة، وأكثر من 64 إدخالًا، والحاويات المتداخلة، وسلاسل الأقراص الافتراضية، والتحويل، وكل عملية كتابة ZIP؛ تُزال البايتات المؤقتة عند الإغلاق الطبيعي أو الخطأ أو الإلغاء. تقبل حركة FAT ملفًا عاديًا واحدًا أو شجرة أدلة كاملة ودليل هدف موجودًا واحدًا؛ ولا تكتب فوق أو تدمج المدخلات. تستخدم أشجار الأدلة نسخًا ثم حذفًا قابلًا للإلغاء؛ ويحافظ الإلغاء قبل الحذف أو فشل الحذف على الشجرتين المكتملتين، لذلك لا يُدعى أنها ذرية. تُقتصر دفعات بيانات تعريف FAT على إدخالات موجودة مُدرجة صراحةً في صورة FAT قابلة للكتابة أو قسم FAT محدد صراحة. قد تضبط أو تمسح فقط بتات القراءة فقط، المخفية، النظام، والأرشيف القياسية وتطبّق أزمنة إنشاء/تعديل/وصول FAT خالية من المنطقة الزمنية يقدّمها المستدعي. تُرفض الطلبات الفارغة، أو جذر أو المسارات المكررة، والرموز النمطية، والتكرار، والأزمنة الضمنية الحالية، وأنظمة الملفات غير-FAT، والأجهزة، وتغييرات ACL/ADS/الملكية، والاختيار التلقائي. يحدد معاينة الدفعة الكتابة، لكن لا يُدعى أن تحديثات دلائل FAT المتعددة لديها تراجع شامل أو لا ينقسم. تم تقييد إنشاء الملفات القديمة عمدًا إلى قطاعات مسطحة متوافقة مع FAT بحجوم 512 أو 1024 أو 2048 أو 4096 بايت؛ تظل الوسائط ذات قطاعات 128/256 بايت، أو تشفيرات GCR أو المتغيرة، أو الأقراص ذات المسامير الصلبة، أو أنظمة الملفات غير-FAT، أو المسارات المحمية بالنسخ، أو لقطات تدفق/فتحة البتات ضمن سير عمل الحفظ/التفتيش الخام. قم بتكوين `qemu-img` عبر **Tools → Preferences** عند الحاجة إلى تحويل الأقراص الافتراضية. يتطلب التصفح للقراءة فقط لـ NTFS/EXT/HFS/HFS+ وجود Sleuth Kit محليًا `fls` و`icat`؛ يتطلب الحقن المسيطر الاختياري أدوات `ntfscp`/`ntfsls`/`ntfscat`، `debugfs`/`e2fsck`، أو، لـ HFS الكلاسيكي فقط، `hmount`/`hcopy`/`hls` للحقن أو `hformat` للإنشاء المؤكد. لا يقوم DiskForge بتنزيل أو تركيب أو تشغيل محول خارجي بصمت. اقرأ [FILESYSTEM_INJECTION.md](docs/FILESYSTEM_INJECTION.md) لعقد النسخ-عند-الكتابة الدقيق والمسارات غير المدعومة.

## جودة هندسية

يتضمن المشروع تغطية آلية للاختبارات لـ إنشاء FAT، ونقل الملفات العادية الآمن، وتجسيد وتنظيف حاويات ZIP الآمنة متعددة الصور ذات الاختيار الصريح، واسترداد مرشح حذف FAT المحافظ، وفحص IMD للقراءة فقط وتصدير RAW صارم، وفحص TD0 للقراءة فقط وتصدير RAW مؤكد CRC صارم، وتحديثات بيانات تعريف FAT متعددة المسارات الصريحة عبر CLI/SDK/الدفعات/سطح المكتب، وجرد دفعات للصور للقراءة فقط مع تصفية وتقارير JSON/CSV/HTML، وتحرير البيانات الوصفية المتقدم، وإنشاء ISO قابل للتمهيد وفحص El Torito، والحفاظ على قالب BPB الأصلي، وتصفح VHD ثابت مؤقت وتنظيفه، وتخطيط النشر، وتقارير صفر الطرف الحافظة، وعقود السحب والإفلات الأصلية، وتحرير وصفة الدفعات الرسومية الكاملة وعدم وجود تأثيرات قبل التشغيل، وسلوك عرض المستند/البحث/الحفظ-للخلف، واستعراض الدليل المقسم صفحات، وتغطية سبع لغات لمساحة العمل الكاملة، وواجهات API علنية للجلسات، وإعدادات محمولة، وتاريخ مركز المهام، وعروض دلائل مستمرة وتفضيلات الخط، واختيار السمة، وتصنيف أجهزة بصرية عبر الأنظمة، والمجاميع الاختبارية، وحزم الصور الموثقة، وإعادة التحجيم الآمن، وتشخيصات GPT CRC، وحماية دورة حياة MBR، وتكامل EXT للقراءة فقط، ومستخرجات ذاتية، وأمان كتابة الجهاز، وتصدير الدليل، وضغط FAT القائم على إعادة البناء. يستخدم pytest تهيئة صارمة، وفحوص علامات صارمة، وسلوك تحذير كخطأ؛ كما يتم التحقق من واجهة المستخدم في بيئة غير مرئية. تقوم التكامل المستمر بتشغيل نفس بوابة الجودة على Windows وLinux وmacOS Intel وmacOS Apple Silicon، ثم تعبئة كل هدف أصلي. يتم التحقق من علامات الإصدارات مقابل بيانات مشروع الوصف وتتسبب نسخة إصدار موجودة مسبقًا في فشل النشر بدلًا من الكتابة فوق أصوله.

```bash
QT_QPA_PLATFORM=offscreen pytest
QT_QPA_PLATFORM=offscreen python scripts/gui_smoke.py
QT_QPA_PLATFORM=offscreen python scripts/gui_i18n_smoke.py
```
